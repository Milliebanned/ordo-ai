# Ordo Demo Script — IBM Bob 2.0 Hackathon

**Total time: 5 minutes**
**Demo repo: `https://github.com/expressjs/express`** (64k stars, well-known, real debt)

---

## Before You Start (do this before judges arrive)

1. Start backend: `cd ordo-backend && npm run dev`
2. Start UI: `cd ordo-ui && npm run dev`
3. Open [http://localhost:5173](http://localhost:5173) in browser
4. Open IBM Bob in a second window, switch to **Ordo** mode
5. Pre-warm: run the analysis once so results are cached, restart the backend after

---

## Minute 1 — The Problem (30 sec pitch)

> "Software teams carry invisible technical debt. Tools like SonarQube give you 200 findings with no priority and no fix path. Ordo does three things they don't: it ranks debt by actual business risk, it explains *why* in plain English, and it generates a ready-to-use PR summary you can paste directly into GitHub."

---

## Minute 2 — Bob Chat Demo

In the Bob **Ordo** mode, type:

```
Analyze https://github.com/expressjs/express
```

**Say:** "I'm using Ordo through IBM Bob — it's a first-class custom mode, not a chatbot wrapper. Watch it call the backend and return a structured debt report."

Wait for response. Then type:

```
Explain issue #3
```

**Say:** "This is the conversational drill-down. Instead of just seeing a score, I can ask *why* this is ranked here and get an AI explanation in plain language — powered by ibm/granite-3-8b-instruct on watsonx.ai."

---

## Minute 3 — Web UI: Debt Dashboard

Switch to the browser. Point out:

1. **Summary bar** — total issues, high/medium/low split
2. **Issue list** — ranked by urgency, with AI-powered scores
3. **Category chart** (Overview tab) — visual breakdown
4. **"✦ AI-enriched"** badge — confirms watsonx.ai ran
5. **"Powered by watsonx.ai · ibm/granite-3-8b-instruct"** attribution at bottom

**Say:** "Every score here was generated by watsonx.ai. The model saw the code snippet, the file path, and the context, and returned a structured JSON response with urgency, impact, and effort scores."

---

## Minute 4 — Roadmap Tab

Click the **Roadmap** tab.

**Say:** "Ordo doesn't just list issues — it sequences them into a 3-phase maintenance plan. Phase 1 is fix-now: security issues and critical reliability gaps. Phase 2 is stability. Phase 3 is code quality. The rationale for each phase is generated by the same Granite model."

---

## Minute 5 — The Wow Moment: Fix Plan + PR Summary

Click on issue #3 (or the hardcoded secrets issue). Click **"Generate Fix Plan + PR Summary"**.

Wait 5–10 seconds.

**Point out:**
- The step-by-step remediation plan
- The code hints (specific APIs to use)
- The effort estimate
- The **PR Summary** — properly formatted GitHub markdown
- The **"Copy PR Summary"** button

**Say:** "This PR summary is production-ready. I paste this directly into GitHub, create the PR, and the model attribution is in the footer — `Generated by Ordo AI Maintenance Engineer | Powered by watsonx.ai (ibm/granite-3-8b-instruct)`. Full traceability."

## Closing Line

> "Ordo turns a 200-item noise report into a prioritized action plan with one click. It runs inside IBM Bob as a first-class mode, uses watsonx.ai for all reasoning and generation, and produces output engineers can actually use — not just read."

---

## Backup: If watsonx.ai is slow or rate-limited

- The backend has a graceful fallback: it returns heuristic scores without crashing
- The UI will show "Heuristic scores" instead of "AI-enriched"
- Tell judges: "Without credentials, Ordo falls back to rule-based scoring — the pipeline still works end-to-end"
- Have a screenshot of a fully AI-enriched run ready as backup

## Backup: If the live demo breaks

- Have the backend pre-running and analysis pre-cached
- `currentAnalysis` is in-memory — it persists for the session
- Just reload the UI and click Roadmap tab — no re-analysis needed
