# Ordo — AI Maintenance Engineer

> Identify technical debt, prioritize issues, generate remediation plans, and prepare fixes — before problems become expensive.

Built for the **IBM Bob 2.0 Hackathon** · Powered by **watsonx.ai** · Model: `ibm/granite-3-8b-instruct`

---

## What is Ordo?

Ordo is an AI maintenance engineer that scans a GitHub repository, detects technical debt across 5 categories, scores every issue by urgency and business impact using watsonx.ai, generates a phased roadmap, and produces ready-to-use remediation plans and PR summaries — all accessible through a polished web UI or directly through IBM Bob chat.

### Demo flow

```
1. Paste a GitHub URL → Ordo scans the repo (no cloning required)
2. View the Debt Dashboard → scored issues ranked by urgency
3. View the Roadmap → 3-phase maintenance plan from watsonx.ai
4. Click any issue → Generate Fix Plan + PR Summary (copy to GitHub)
5. Or: use Bob chat → "Analyze https://github.com/expressjs/express"
```

## IBM Cloud Setup (15 minutes)

1. Sign up at [cloud.ibm.com/registration](https://cloud.ibm.com/registration) (free)
2. From the dashboard: **Create resource** → search "watsonx.ai Studio" → **Lite (free)** → Create
3. Open watsonx.ai → **New project** → copy the Project ID UUID from the browser URL
4. Top menu → **Manage** → **IAM** → **API keys** → **Create** → copy the key
5. Optional: [Create a GitHub PAT](https://github.com/settings/tokens) with `public_repo` scope

## Setup & Run

### 1. Configure credentials

```bash
cp ordo-backend/.env.example ordo-backend/.env
```

Edit `ordo-backend/.env`:
```
WATSONX_API_KEY=your-iam-api-key
WATSONX_PROJECT_ID=your-project-uuid
WATSONX_REGION=us-south
GITHUB_TOKEN=your-github-pat   # optional
```

### 2. Start the backend

```bash
cd ordo-backend
npm install
npm run dev
# → Running on http://localhost:3001
```

### 3. Start the UI

```bash
cd ordo-ui
npm install
npm run dev
# → Running on http://localhost:5173
```

### 4. Open Ordo

→ [http://localhost:5173](http://localhost:5173)

Paste a GitHub URL and click **Analyze**.

Switch to the **Ordo** mode in IBM Bob. Then:

| `Explain issue #3` | AI rationale for why it's ranked there |
| `Generate fix for issue #2` | Remediation plan + copy-ready PR summary |
| `Show me the roadmap` | 3-phase maintenance plan |

## Debt Categories Detected

| # | Category | What it finds |
|---|---|---|
| 1 | **Hardcoded Secrets** | API keys, passwords, tokens in source code |
| 2 | **Complex Functions** | Functions >50 lines or nesting depth >4 |
| 3 | **Thin Test Coverage** | Source files with no corresponding tests |
| 4 | **Outdated Dependencies** | Wildcard versions, unpinned packages, missing lockfile |
| 5 | **Undocumented APIs** | Exported functions/classes lacking JSDoc or docstrings |

---

## watsonx.ai Usage

Every debt item is enriched by `ibm/granite-3-8b-instruct` with:
- Debt type classification (security / reliability / maintainability / performance / test-coverage)
- Urgency score (1–10)
- Business impact score (1–10)
- Fix effort score (1–10)
- Plain-English business risk explanation

Roadmap, remediation plans, and PR summaries are all generated by the same model.
